# ⚡ Zyra Loading Screen 1 - Cyberpunk / Synthwave Edition

Welcome to **Zyra-Loading-Screen-1**, a high-impact FiveM loading screen resource by **Zyra Store**. Featuring a dark split-screen Cyberpunk/Synthwave layout with neon glowing accents, interactive canvas particles, and a fully custom audio player for FiveM roleplay servers.

## 🛠️ Key Features

- **Cyberpunk / Synthwave Visual Design:** Dark split-screen layout with glowing neon cyan and magenta accents.
- **Interactive Particle Background:** Dynamic HTML5 canvas particles with background video and image slider support.
- **Integrated NUI Music Player:** Customizable music playlist with audio visualizer equalizer and volume controls.
- **Server Rules & News Accordion:** Collapsible panels displaying server announcements, patch notes, and roleplay rules.
- **Social Media Quick Links:** Interactive buttons linking to Discord, Tebex Store, YouTube, Website, and social channels.
- **100% Configurable:** Easy customization through `config.js` without modifying HTML/CSS code.

---

## 📦 Installation Instructions

1. **Copy the Resource:**
   Place the `Zyra-Loading-Screen-1` folder into your FiveM server's `resources` directory:
   `resources/[zyra]/Zyra-Loading-Screen-1`

2. **Configure `server.cfg`:**
   Add the following line to your `server.cfg` file:
   ```cfg
   ensure Zyra-Loading-Screen-1
   ```

3. **Start / Restart Server:**
   Save `server.cfg` and restart your server, or run the following commands in the server console:
   ```cmd
   refresh
   ensure Zyra-Loading-Screen-1
   ```

---

## ⚙️ Configuration Guide (`config.js`)

Open `config.js` in any text editor to customize your loading screen:

- **Server Branding:** Set your server name, subtitle slogan, and logo URL.
- **Music Playlist:** Add direct `.mp3` music links, song titles, artists, and default playback volume.
- **Social Links:** Update URLs for Discord, Tebex store, and community platforms.
- **Rules & News:** Edit the announcements, update logs, and server rule accordion items.
